# Timer Dashboard

A lightweight, mobile-first focus timer and productivity dashboard by NATIONVK.

## Core areas
- Blue Particle Heart focus environment (ported from FOCUS-FLOW-4.0)
- Focus timer with pause, resume, finish and session restore
- Dashboard with daily/weekly totals, streak, subject breakdown, monthly activity calendar, recent sessions and CSV export

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

All study data is stored locally in this browser. This repository is independent from FOCUS-FLOW-4.0; the source repository is reference-only.
